# agents/tmp/ — scratch space

Temporary files of the agent: drafts of dialog texts, intermediate outputs, quick experiments,
downloaded logs. Everything in this folder except this README is ignored by git (see `.gitignore`),
so nothing here is kept in the project history.

Rules:
- Use this folder instead of the project root or system temp folders for anything temporary.
- Anything worth keeping moves to `agents/notes/` (notes) or `agents/memory.md` (long-term memory).
- Safe to empty at any time (keep this README).
